4最小权限

Job A · 跑 PR 代码

contents: read，其余全 none。不需要评论、不需要密钥。

Job B · 持密钥

contents: read + pull-requests: write。只够读 diff、发评论。

小练习：公开仓库 + 默认 Read and write + on: pull_request + 声明 pull-requests: write + PR 来自公开 fork，能发评论吗？

不能。 fork 的 pull_request 会把写权限降为只读，写评论 403——声明的是“请求”，不是“授予”。
