# Store assets

- `logo-300.png` — 300×300 store logo (required for each language; can duplicate).
- `small-promo-440x280.png` — optional small promotional tile.
- `large-promo-1400x560.png` — optional large promotional tile.
- `make_assets.py` — regenerates the logo/tiles from `icons/icon128.png`.

**Screenshots are not bundled.** Capture 1–6 real screenshots from a logged-in Edge session:

- Size: **1280×800** or **640×480**.
- Show the actual side panel, not test pages or fake chat text.
- Recommended: page preview + file/direct fill buttons; prompt library; PDF reader; quote button over a real DeepSeek reply.
- Do not stretch or blur; keep text readable.
